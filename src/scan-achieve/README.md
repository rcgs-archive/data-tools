# Discord作業報告パーサー

## 概要

Discordの作業報告ログから作業時間、資料数、ページ数を抽出し、日毎の集計と生産性を計算するツールです。

## 機能

- **Discordログの解析**: テキストファイルから作業報告を抽出
- **作業時間の抽出**: ISO8601 Duration形式（PT2H、PT3H30Mなど）から作業時間を計算
- **日毎の集計**: 日付ごとに作業時間、資料数、ページ数を集計
- **生産性の計算**: ページ/時間の生産性指標を自動計算
- **日付の自動判定**: タイムスタンプや「昨日」などの相対日時に対応
- **日付上書き対応**: 「（11/4日のぶん）」などの日付指定に対応

## 使用方法

```bash
# デフォルトファイル名（discord_log.txt）を使用
python parse-discord.py

# ファイルパスを指定
python parse-discord.py discord_log.txt

# 別のファイルを指定
python parse-discord.py /path/to/your/log.txt
```

## 入力ファイル形式

Discordのログをそのままテキストファイルに貼り付けてください。

```
XXXXX — 
2025/10/13 17:52
作業時間PT2H、撮影完了4資料70ページ

YYYYY — 
2025/10/17 15:56
作業時間PT4H30M、撮影完了8資料123ページ
```

## 出力

- **日毎の出来高と生産性**: 日付ごとの作業時間、資料数、ページ数、生産性（ページ/時間）
- **全期間合計**: 総ページ数、総資料数、総作業時間

## 必要なライブラリ

- pandas
- Python標準ライブラリ（re, sys, datetime）
